# 현황 감사 — 코드베이스·문서의 실제 상태 (Cycle 0)
> 2026-08-19 기준, 실행·grep 으로 직접 확인한 것만 적는다. 「직접 실행」·「코드 정독」·「미확인」을 구분한다. 이 레포 한정. 감사 주체: 자율 사이클 세션 (운영 규약 0.1·0.2).

## 1. 이 저장소는 현재 무엇인가

풀스택 스타터 템플릿(멀티테넌트 관리자·MCP 서비스 군) 위에 **개인 투자 지휘소**를 짓는 중인 모노레포다. 실제로 도는 것: 로그인 → 실험대(봇 만들기·조건 편집, Claude 대화 폼 채움) → 시세 터미널(샘플 소스 적재·차트) → 설정(데이터 키 상태·저장) → `/admin` 관리 화면 → 저녁 배치용 AI 리서치 챗(멀티 에이전트, MOCK 데이터 기동). 백테스트 엔진·격자·지표는 main 에 있고 화면 배선까지 끝났다. **없는 것**: 실시세(자격 IP 화이트리스트 대기), 장중 봇 실행, 주문(코드 레벨 차단), 스크리너. 문서 54개 중 상당수가 템플릿 시절 것이고, 제품 방향 문서(prd)는 2026-07-28 이후의 큰 결정들(토스 API 채택·paper trading 자체 시뮬레이터·M2 완주)을 아직 모른다. **포장 없이 말하면**: 골조와 안전장치는 실하나, 트레이딩 제품의 핵심 루프(실데이터 → 검증 → 모의 운용)는 첫 칸(실데이터)에서 외부 의존(IP 등록) 하나로 막혀 있는 상태다.

## 2. 구조·버전·엔트리포인트 (직접 확인)

- 모노레포: `frontend`(Next.js 16.3, Node 24) + `backend-service`(FastAPI, Python >=3.12<3.13, uv) + MCP 서비스 7종(:8002~8009) + `multi-agent-service`(:8003) + `bot-agent-service`(Claude Agent SDK) + `platform/`(nginx·litellm)

### 7.2 중복 코드·개념 표현 불일치

- **가격 표현이 계층마다 다르다**: 어댑터 `NormalizedBar` = `Decimal`, DB = `Numeric(20,4)`, **백테스트 엔진 = `float`** (`engine.py:41-45`), 프론트 = `number`. 엔진 float 는 성능 목적으로 통상적이나, **paper trading 시뮬레이터의 현금·체결 회계에 float 를 재사용하면 안 된다** → 시뮬레이터 설계 시 Decimal 경계 필수. 분류: 제품 정의 확정 후 정리 (경계 문서화)
- 종목 식별: `(market, symbol)` 복합키 + `instrument_id` 대리키 + alias(`tn_symbol_alias`) — **일관됨** (MD-AD-13, 코드 정독)
- 시간대: KST 고정 가정이 어댑터별 상이 — data_go_kr(날짜 기반)·toss(+09:00 ISO — **실캔들 미검증**)·sample(날짜) → 실호출 후 대조 필요. 분류: 기록만(블로커 해소 후)

### 7.3 외부 API 실패 처리·한도

- providers 공통: 429/5xx 백오프 재시도(`retry_utils`)·`ProviderKeyMissing`·capability 사유 — **일관 적용** (alpaca·toss 코드 정독, 그물 통과)
- 토스 클라이언트: 공식 한도(AUTH 5/s·MARKET_DATA 15/s·CHART 20/s) 대비 1/s·4/s·4/s 보수 설정 + 토큰 만료 여유 갱신 (직접 구현·그물 19건)
- **미확인**: 한도 초과 시 토스의 실제 응답(429 형식·제한 기간) — 실호출 대기

### 7.4 백테스트 엔진의 한계 (0.0.3-4 실측과 연결)

표현 가능: 수수료·슬리피지·증권거래세 3종뿐. **없음**: 호가 단위(구간별 tick)·가격제한폭(±30%)·동시호가·VI·거래정지·일별 거래대금 대비 체결 가능 물량·코스피/코스닥 세율 구분·수정주가 계수 적용. 실측: 현실 회전(14~44건/7.5개월)에서 명시 비용 3종만으로 수익률 3.7~8.2p 차이·**부호 반전** 발생 — 없는 제약까지 넣으면 차이는 더 벌어진다. **가설 A 의 「국내 제약 미반영」은 우리 엔진에도 그대로 해당**한다. 분류: 제품 정의 확정 후 (차별화의 핵심 후보)

### 7.5 판단 — 계속 갈 것인가, 재구성할 것인가

**계속 간다.** 근거: ① 테스트·그물·CI 가 촘촘하고 전부 초록 — 바닥이 썩지 않았다 ② 최근 명시된 불일치는 대부분 「문서가 낡음」이지 「코드가 낡음」이 아니다 ③ 재구성이 필요한 축(백테스트 현실성·paper trading)은 **추가**이지 뒤엎기가 아니다. 멈추지 않고 진행한다 (운영 규약 0.2).
