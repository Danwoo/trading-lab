# 의사결정 로그 — 제품·아키텍처 확정 결정 (ADR, append only)
> 자율 사이클(Cycle 0~10)에서 리드가 확정한 결정을 시간순으로 쌓는다. 수정·삭제 금지 — 뒤집을 때는 새 항목으로 뒤집는다. 코드·화면 결정의 역사적 원본은 루트 [CONTEXT.md](../../CONTEXT.md) 결정 로그이며, 이 문서는 제품 국면(2026-08-19 운영 규약)부터의 결정을 담는다.

## 1. 2026-08-19 — API 키는 앱이 각 서비스의 `.env` 에 직접 쓴다

- **맥락**: 키가 10개 서비스에 흩어져 있고 MCP 서비스에는 DB 가 없다. DB 저장은 한 서비스에만 닿는다.
- **결정**: 설정 화면의 키 저장은 해당 서비스 `.env` 파일의 그 변수 한 줄만 원자적으로 간다. 백업 파일은 남기지 않는다(평문 사본 금지). 반영은 재기동 — 화면이 그 사실을 말한다.
- **결과**: `#225` PR A(#246)·PR B(#248) 착륙. 로컬판 전용(fail-closed), 호스팅에서 비활성.

## 2. 2026-08-19 — 주문 계열 호출은 코드 레벨에서 차단한다

- **맥락**: 토스증권 Open API 에 sandbox 가 없다(공식 문서 확인) — 첫 주문이 곧 실거래다.
- **결정**: `TRADING_LIVE_ENABLED` 가 문자열 `true` 와 정확히 일치할 때만 주문 경로가 열린다. 기본 닫힘, 기본값 변경은 리드 승인 사항. 계좌 조회는 호출부 명시 플래그가 있어야 한다.
- **결과**: `providers/toss/live_guard.py` + 그물 19건 (`tests/test_toss_order_guard.py`).

## 3. 2026-08-19 — Paper trading 은 자체 체결 시뮬레이터로 간다 (방향 확정, 0.4 에서 재확정)

- **맥락**: sandbox 부재로 모의 거래는 자체 구현 대상. 대안은 KIS 모의투자(타사 체결 엔진).
- **결정**: 1차는 자체 시뮬레이터 — 가설 A 실측(비용 3종만으로 3.7~8.2p 차이·부호 반전)이 보여준 차별화 지점(현실적 체결 가정)과 백테스트 엔진에 없는 KRX 제약(호가단위·가격제한폭·거래대금·VI)을 한 곳에서 짓는다. KIS 는 실주문 승격 직전 교차 검증용으로 보류.
- **결과**: 구현은 제품-정의 확정 뒤. 상세 수치는 Cycle 0 기록 참조.

## 5. 2026-08-19 — 두 값 자격(합성 키)도 화면에서 넣을 수 있어야 한다

- **결정**: 사용자 직접 입력 기능은 합성 자격까지 덮는다. 작업은 이슈 #249 — 사이클 백로그에서 선별.
